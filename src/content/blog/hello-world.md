This is the first post. Astro builds the blog from Markdown files in
`src/content/blog/` — drop a new `.md` file in there with the frontmatter
shown above, and it'll appear in the index and RSS feed automatically.

## Writing

Anything Markdown-y works: **bold**, _italic_, [links](https://astro.build),
lists, and code blocks.

```ts
const greet = (name: string) => `Hello, ${name}`;
console.log(greet('world'));
```

> Block quotes are styled with a left rule in the site accent color.
